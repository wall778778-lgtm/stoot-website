Behind the creation of STOOT.

About The Developer

STOOT is an independent game project created by a developer interested in programming, game development and learning new technologies.

The project started as an idea to create a simple space shooter and gradually evolved into a complete game with combat systems, asteroid destruction, enemies and progression mechanics.

Development Philosophy

The goal of STOOT is to create an enjoyable gameplay experience while continuously improving programming and game development skills.

Every part of the game is developed as an independent project, from gameplay systems to the website that shares the game with players.

Technology Used

STOOT is developed using:

• C++ programming language
• SFML multimedia library
• Custom gameplay systems built from scratch

Future Goals

Development of STOOT is continuing. Future improvements may include new enemies, additional gameplay mechanics, better visuals and more challenging experiences for players.
